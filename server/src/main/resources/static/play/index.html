Sudoku grid, 9 rows by 9 columns. Use the arrow keys to move between cells, Home and End for the first and last column, Page Up and Page Down for the first and last row. Type 1 to 9 to enter a digit, and 0, Backspace or Delete to clear a cell. Press N to toggle notes mode. Control Z undoes, Control Y redoes.
